# Эмонг Ас — лендинг квеста «Выживание на корабле», Улан-Удэ

Одностраничный сайт для квеста по игре Among Us (Instagram: @amongus_v_uu). Готов к публикации: открывается `index.html`, стили — `css/style.css`, скрипты — `js/main.js`.

## Структура
```
index.html            — страница (10 блоков)
css/style.css         — стили, адаптив 320–1920 px
js/main.js            — меню, слайдер отзывов, карта корабля, калькулятор, карты ролей
img/                  — изображения WebP + JPG-фолбэк, иконки, og.jpg
video/                — сжатое видео (H.264, faststart) + постер
robots.txt, sitemap.xml, llms.txt  — SEO и GEO (поисковики и нейросети)
manifest.webmanifest, favicon.ico, .htaccess
keywords.md           — семантическое ядро
```

## Блоки
1. Первый экран — «кнопка экстренного собрания», иллюминатор с астронавтом, цифры площадки
2. О квесте — видео-обзор и фото входа
3. Роли — переворачивающиеся карты «Член экипажа» и «Предатель»
4. Ход игры и экипировка
5. Интерактивная карта корабля — 10 зон
6. Форматы и цены — билеты + калькулятор стоимости
7. Поводы: день рождения, класс, компания, коллектив
8. Отзывы — слайдер (свайп, стрелки, автопрокрутка)
9. FAQ (с микроразметкой FAQPage)
10. Контакты и Яндекс.Карта

Пасхалка: кнопка «Не нажимать» в подвале запускает «саботаж» с призывом забронировать.

## Перед публикацией
- Домен-заглушка `https://emongas-uu.ru` — заменить поиском по всем файлам на реальный (index.html, robots.txt, sitemap.xml, llms.txt).
- Описания зон корабля (js/main.js, массив `Z`) написаны атмосферно — сверить с заказчиком.
- Карта ищет адрес «Улан-Удэ, ул. Каландаришвили, 27а»; при желании поставить точную метку через конструктор Яндекс.Карт.
- Хостинг: подходит любой статический (GitHub Pages, Netlify, обычный хостинг). `.htaccess` работает на Apache.
